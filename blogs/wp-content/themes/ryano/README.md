# Ryano Blog Theme

Custom WordPress theme matching Ryano's portfolio design (ryanoccg.com).

## Features

- Dark theme with blue accent color (#069AFF)
- Responsive grid layout for blog listing
- Clean single post template
- Reading time calculation
- Post navigation (prev/next)
- Custom pagination
- Lightweight and fast

## Design Tokens

- Primary color: #069AFF
- Background: #161616
- Text: #FFFFFF
- Muted text: #CCCCCC

## Installation

1. Upload theme to `wp-content/themes/ryano/`
2. Activate in WordPress Admin → Appearance → Themes
3. Configure menu in Appearance → Menus (optional)

## Templates

- `index.php` — Blog listing (home page)
- `single.php` — Single post page
- `header.php` — Site header
- `footer.php` — Site footer
- `style.css` — Main stylesheet
- `functions.php` — Theme functions
